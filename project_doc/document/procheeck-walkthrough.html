Phase 0 review
For Ale

Before you start: everything here runs on mock data held in the browser's memory. Nothing you create, edit, or delete is permanent — a refresh of the tab can reset it back to the starting fixtures. That's intentional for this stage (see "What's not real yet" below), not a bug.

  1. Open ‹ link goes here once we deploy › — until then, this is the same map for the local dev copy.
  2. The site opens in Spanish by default (our confirmed primary market). Switch to English anytime with the ES / EN toggle, top right of every page.
  3. To see a signed-in view, click Sign in, type any email and any password — this prototype doesn't check credentials yet, so both fields just need something in them.
  4. Once inside, look for the dashed "Test role" button next to the language toggle. That's the real way to switch who you're looking at the platform as — not the login screen. Click it and pick from the 5 roles below; the whole app re-renders instantly as that person.

03What's not real yet

So nothing here reads as a bug when it's actually a deliberate boundary of this stage:

–No real payments — checkout completes but nothing is charged
–No real invoicing or DC-3 folio issuance
–No real email delivery
–No data survives a hard refresh — it's all in-browser mock data
–Login accepts anything — the "Test role" switcher is the real controls
–No mobile app — this is a responsive site, not native
–No dark mode toggle exposed yet (it's built, just hidden)
PROCHEECK — Phase 0 prototype, built to spec against the approved build plan. Questions on anything above? Just ask.
